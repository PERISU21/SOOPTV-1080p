# SOOP 1080p 브레이브 플레이어

Ubuntu에서 공개 SOOP 생방송의 H.264/AAC 원본을 받아 브레이브에서 재생합니다. **브레이브 확장을 사용하면 SOOP 목록에서 방송을 누른 원래 탭의 영상 영역에서 1080p·720p와 SOOP 기본 화질을 전환**할 수 있습니다. 채팅 등 나머지 화면은 그대로 이용합니다. 고화질 방송은 최대 세 탭을 동시에 재생합니다. SOOP 공식 기능이나 공식 배포물은 아닙니다.

## SOOP 원본 탭에서 재생하기

1. 이 PC에는 [soop-ubuntu-bridge.service](/home/ubuntu/Documents/ChatGPT/숲TV_1080p/soop-ubuntu-bridge.service)가 사용자 서비스로 등록되어 **Ubuntu 로그인 시 자동 시작**됩니다. 재생 서버는 `127.0.0.1:18777`에서 실행됩니다. 재생이 안 되면 `systemctl --user status soop-ubuntu-bridge.service`로 상태를 보고, 꺼져 있으면 `systemctl --user start soop-ubuntu-bridge.service`로 다시 켭니다. 서버가 이미 실행 중일 때 [start_soop_bridge.sh](/home/ubuntu/Documents/ChatGPT/숲TV_1080p/start_soop_bridge.sh)나 [SOOP_원본탭_고화질.desktop](/home/ubuntu/Documents/ChatGPT/숲TV_1080p/SOOP_원본탭_고화질.desktop)을 중복 실행하지 않습니다.
2. 브레이브 주소창에 `brave://extensions`를 열고 **개발자 모드**를 켭니다. **압축해제된 확장 프로그램을 로드합니다**를 눌러 [brave_extension](/home/ubuntu/Documents/ChatGPT/숲TV_1080p/brave_extension) 폴더를 선택합니다. 이미 설치했다면 확장 카드의 **새로고침** 버튼을 누릅니다. 그다음 열린 SOOP 방송 탭을 새로고침합니다.
3. 평소처럼 SOOP 목록에서 방송을 누릅니다. 영상 오른쪽 위 **화질 선택** 또는 고화질 영상 아래 조작바에서 `1080p 고화질`, `720p 고화질`, `540p SOOP`, `360p SOOP`, `자동 SOOP`를 고릅니다. 처음에는 1080p가 선택됩니다. 고화질 화면의 **원본 1920 × 1080** 또는 **원본 1280 × 720** 표시는 실제 디코딩된 픽셀 크기입니다. 세 방송을 새 탭으로 열었다면 **각 탭을 한 번씩 눌러** 초기 재생을 시작합니다. 자동재생이 막힌 탭은 영상의 ▶ 버튼을 누릅니다.

| 선택 | 재생 경로 | 실제 영상 |
|---|---|---|
| 1080p 고화질 | 이 앱의 SOOP 원본 수신 | 1920 × 1080 |
| 720p 고화질 | 이 앱의 SOOP 원본 수신 | 1280 × 720 |
| 540p SOOP | SOOP 기본 플레이어 | SOOP 설정에 따름 |
| 360p SOOP | SOOP 기본 플레이어 | SOOP 설정에 따름 |
| 자동 SOOP | SOOP 기본 플레이어 | SOOP 자동 선택 |

720p는 1080p를 축소해 다시 인코딩하는 방식이 아닙니다. SOOP 미디어 서버에서 **품질 비트 `2`만 요청**해 받은 실제 1280 × 720 H.264 원본을 재포장합니다. 프레임 속도는 방송마다 다릅니다. 이전의 품질 값 `10`은 `2 | 8`이라 720p와 360p를 한 재생목록에 섞어 브라우저 재생을 망가뜨렸습니다. SOOP 방송 자체가 해당 화질을 제공하지 않거나 서버 정책이 바뀌면 재생되지 않을 수 있습니다.
선택한 화질은 해당 탭에서 새로고침해도 유지됩니다. 540p·360p·자동은 SOOP 기본 플레이어를 사용하므로 그 화면의 화질 메뉴에서도 다시 바꿀 수 있습니다.

고화질 영상 아래 조작바는 항상 표시됩니다. 왼쪽의 **▶/⏸**는 재생과 일시정지, **■**는 수신까지 종료하는 중지, **🔊**와 슬라이더는 음소거와 음량, 빨간 **● LIVE**는 실시간 위치로 이동하는 버튼입니다. 오른쪽에서 화질과 전체 화면을 바꿀 수 있습니다. 중지한 뒤 **▶**를 누르면 고화질 수신을 다시 시작합니다.

고화질 재생의 첫 음량은 **30%**입니다. 음량이나 음소거를 바꾸면 브레이브 확장에 저장되어 1080p와 720p를 전환하거나 방송 탭을 새로 열어도 마지막 설정을 사용합니다. 브레이브를 다시 실행한 뒤에도 유지됩니다. SOOP 기본 화질(540p·360p·자동)의 음량은 SOOP 원래 플레이어가 관리합니다. 확장 파일을 수정한 뒤에는 `brave://extensions`에서 확장을 새로고침하고 열린 방송 탭도 새로고침해야 적용됩니다.

SOOP 기본 화질(540p·360p·자동)로 내려가도 영상 오른쪽 위의 **확장 화질 선택** 메뉴는 남아 있어야 합니다. 여기에서 다시 720p·1080p를 선택합니다. SOOP 자체 화질 메뉴의 1080p를 누르면 공식 스트리머 설치 안내가 나올 수 있으므로 확장 메뉴를 사용하세요. 화면 크기를 바꾸는 동안 SOOP 영상 요소가 잠시 작아지거나 교체되어도 고화질 재생창은 숨겨지지 않습니다. 720p 재생 상태는 로컬 서버의 `browser-telemetry.json`에 기록됩니다.

고화질에서 SOOP 기본 화질로 돌아갈 때는 뒤에서 일시정지되어 있던 SOOP 영상을 다시 재생하고, 생방송 구간의 끝으로 이동합니다. SOOP가 화질 전환 중 영상 요소나 재생 구간을 갱신할 수 있어 전환 직후 몇 차례 현재 위치를 확인합니다.

1080p·720p를 선택한 탭은 각각 별도의 고화질 수신을 사용합니다. 540p·360p·자동으로 바꾸면 해당 탭의 고화질 수신을 종료하고 SOOP 기본 플레이어를 다시 켭니다. 탭을 닫으면 해당 수신을 종료하며, 예기치 않게 닫혀도 일정 시간 뒤 정리합니다. 고화질 재생 중에는 원래 SOOP 영상을 음소거·일시정지하고 고화질 영상을 그 위치에 겹쳐 표시합니다. 채팅과 페이지의 다른 부분은 원래대로 남습니다. 확장은 `play.sooplive.com`과 이 PC의 `127.0.0.1:18777`에만 접근하도록 설정했습니다. 기존 별도 플레이어까지 함께 재생하면 그 재생도 세 개 제한에 포함됩니다.

이번 확인에서 **서로 다른 공개 방송 세 개**를 브레이브 탭으로 열었고, 세 탭의 `videoWidth`·`videoHeight`가 모두 **1920 × 1080**, `paused=false`, `readyState=4`였습니다. 방송인 ID와 방송번호는 공개 문서에 기록하지 않습니다.

방송번호는 시간이 지나면 바뀔 수 있으므로 평소에는 SOOP 목록에서 현재 방송을 누르세요. 확장을 로드하지 않거나 로컬 수신 서버가 꺼져 있으면 SOOP의 기본 화질로 재생됩니다.

## 별도 로컬 플레이어로 재생하기

현재 PC에 Python 3, FFmpeg, Brave가 필요합니다. 작업 폴더에서 다음을 실행합니다. 파일 관리자에서 [SOOP_Brave.desktop](/home/ubuntu/Documents/ChatGPT/숲TV_1080p/SOOP_Brave.desktop)을 실행해도 됩니다. Ubuntu가 처음 실행을 막으면 파일을 실행 가능하게 허용해야 합니다.

```bash
cd '/home/ubuntu/Documents/ChatGPT/숲TV_1080p'
sudo apt install ffmpeg
bash start_local.sh
```

브레이브가 열리면 **현재 방송 중인 공개 SOOP 주소**를 입력하고 **방송 재생**을 누릅니다. 방송번호가 바뀌었으면 새 주소를 넣습니다. 브레이브가 자동재생을 막으면 **소리 켜고 재생**을 누릅니다. 화면 아래의 **실제 해상도**는 디코딩된 영상 크기입니다. 전체 화면은 영상 플레이어의 버튼을 사용합니다.

페이지의 **중지**는 미디어 수신을 끝냅니다. 터미널에서 `Ctrl+C`를 누르면 로컬 웹 서버도 종료합니다. 서버가 실행 중일 때 터미널에 표시되는 `http://127.0.0.1:포트/` 주소를 브레이브에 직접 열어도 됩니다. `web/index.html` 파일만 열면 서버가 없어 **연결 실패**가 납니다.

방송 주소를 명령에 바로 지정할 수도 있습니다.

```bash
bash start_local.sh 'https://play.sooplive.com/방송ID/방송번호'
```

문제가 생기면 터미널에 표시되는 **진단 폴더**의 `diagnostics/`와 `browser-telemetry.json`을 확인합니다. 이 자료에는 방송 식별자 등이 포함될 수 있어 공개 공유 전에 내용을 확인해야 합니다.

## 이번에 확인한 결과 (2026-09-28)

- 공개 방송 한 건의 네이티브 수신이 **80.014초 정상 종료**됐습니다. 저장된 FLV의 `ffprobe` 결과는 H.264 1920 × 1080, 60 fps와 AAC 48 kHz 스테레오입니다.
- 실제 브레이브 재생 계측은 **224초** 동안 재생 시간이 11.73초에서 238.00초로 증가했습니다. 마지막 기록은 1920 × 1080, `paused=false`, `readyState=4`, `muted=false`, 볼륨 1이며 영상 프레임 수가 계속 증가했습니다. 자동 계측만으로 스피커 소리까지 확인했다고 표현하지는 않습니다.
- 예전에 약 30초 뒤 수신이 멎던 원인은 미디어 읽기가 멈춘 동안 이어받기 요청도 중단된 점이었습니다. 짧은 소켓 대기와 4초 간격 이어받기 요청으로 고친 뒤 위 연속 수신과 브레이브 재생을 확인했습니다.

현재 경로는 관찰된 공개 H.264/AAC 생방송에 맞춰져 있습니다. 비밀번호 방송, 다른 코덱, SOOP 서버 프로토콜 변경에 대한 호환성은 확인되지 않았습니다.
