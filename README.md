# SOOP Brave 고화질 재생 0.7.6

공개 SOOP 생방송의 1080p·720p 원본을 같은 Brave 방송 탭에서 재생하는 배포본입니다. SOOP 공식 배포물이 아닙니다.

## 포함 파일

- `soop_browser.py`: 이 컴퓨터의 로컬 재생 서버와 탭별 수신 관리
- `soop_player.py`, `soop_media.py`: 방송 원본 수신과 미디어 데이터 처리
- `brave_extension/manifest.json`, `background.js`, `content.js`, `hls.min.js`: Brave 확장
- `brave_extension/hls.LICENSE`: HLS 라이브러리 배포 라이선스
- `README.md`, `576p 예외 사례.md`: 설치 및 예외 동작 안내

압축을 풀었을 때 위 상대 경로를 유지하세요. `private/`, `__pycache__/`, 연구 도구, 별도 플레이어용 `web/`, Ubuntu 전용 서비스와 실행 아이콘은 포함하지 않았습니다.

## 설치 및 시작

1. 같은 컴퓨터에 Brave, Python 3, FFmpeg를 설치하고 `python3 --version` 및 `ffmpeg -version` 또는 Windows의 `py -3 --version` 및 `ffmpeg -version`으로 명령이 실행되는지 확인합니다. FFmpeg는 실행 경로(PATH)에 있어야 합니다.
2. 압축을 푼 폴더에서 로컬 서버를 시작합니다. Ubuntu·macOS: `python3 soop_browser.py --port 18777` / Windows: `py -3 soop_browser.py --port 18777`. 이미 같은 포트의 서버가 실행 중이라면 중복 실행하지 않습니다.
3. Brave에서 `brave://extensions`를 열고 개발자 모드를 켠 후 `brave_extension` 폴더를 압축해제된 확장으로 등록합니다. 기존 설치를 교체했다면 확장 카드의 새로고침을 누릅니다.
4. 열린 SOOP 방송 탭도 새로고침합니다. 확장 버전이 `0.7.6`인지 확인하고 공개 생방송을 엽니다.

서버는 `127.0.0.1:18777`에서만 수신합니다. 이 배포본은 자동 시작 설정을 포함하지 않으므로 서버를 수동 시작한 터미널을 열어 두어야 합니다. 다른 OS에 자동 시작을 설정할 경우 설치한 경로에 맞는 OS별 설정을 따로 만드세요.

## 화질 동작

- 기본값은 1080p입니다. 1080p 시작 단계가 실패하면 720p 원본을 한 번 요청합니다.
- 브라우저가 받은 실제 해상도가 `1280 × 720`이면 메뉴를 720p로 정정합니다.
- 1080p 요청의 영상이 실제 `1024 × 576`으로 디코딩되면 고화질 세션을 종료하고 SOOP 기본 플레이어의 540p를 선택합니다. 자세한 조건은 `576p 예외 사례.md`에 있습니다.
- 540p·360p·자동은 SOOP 기본 플레이어를 사용합니다. 화면의 `원본 너비 × 높이` 배지는 고화질 영상의 실제 디코딩 크기를 나타냅니다.

현재 576p 예외는 1080p 요청에서 실제 `1024 × 576` 영상의 메타데이터가 도착한 경우에 감지됩니다. 1080p와 720p 수신이 모두 영상 메타데이터 없이 실패한 경우에는 이 버전이 자동으로 540p로 돌아간다고 보장할 수 없습니다. 서버 장애나 방송 종료도 같은 실패처럼 보일 수 있습니다. 540p로 직접 선택해 SOOP 기본 플레이어를 이용할 수 있습니다.

이 배포본의 0.7.6 코드에 대해 Ubuntu의 해당 576p 방송에서 실제 540p 복귀를 확인한 기록은 없습니다. 배포 대상 OS에서 확인하세요.
